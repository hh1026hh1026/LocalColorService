# AdaInt model files

Place the official Apache-2.0 `AiLUT-FiveK-sRGB.pth` checkpoint here.  The
default V0.2 service path is `models/adaint/AiLUT-FiveK-sRGB.pth`; override it
with `ADAINT_CHECKPOINT` when the model is stored elsewhere.

Source: https://github.com/ImCharlesY/AdaInt/tree/main/pretrained
